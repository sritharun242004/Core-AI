Choose one bounded extension:

1. Build a fixture-driven router evaluation with easy/hard held-out task slices,
   explicit latency/cost ceilings, cache hit/miss traces and quality uncertainty.
   Compare cheapest-only routing with constraint-aware routing at matched budgets.
2. Compare this teaching MCP subset with the pinned official schema. In a separate
   environment, implement one real SDK adapter using its actual API and fake
   transports. List every unsupported capability; do not call it certified.
3. Design (do not launch) an official SWE-Bench/Inspect AI extension: pin task and
   harness versions, isolation, data permissions, caps, scoring and contamination
   controls. Explain how these differ from the two local fixtures.

Deliver: tests or a reproducible experiment specification, cost sheet, threat model
and one-page limitations report. Optional real ADK experimentation requires the
separate opt-in COMPUTE.md procedure and is not needed for full assignment credit.
