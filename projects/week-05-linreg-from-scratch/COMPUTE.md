# Compute note

**Tier:** 🟢 local CPU · **Expected time:** under 5 minutes for the notebook and tests · **Budget:** $0

The project uses NumPy only and is designed for an Apple Silicon laptop or any recent CPU. No CUDA, MPS, network access, dataset download, or cloud account is required. Keep the synthetic examples small while debugging; the point is the derivation and numerical behavior, not a large benchmark.
