<Hook>Before a model has millions of parameters, it has a line, a loss, and a gradient. Build those three pieces and you can explain the training loop instead of merely calling it.</Hook>

<Intuition>
A linear model is a ruler laid across data: each feature pushes the prediction by a learned amount, and the intercept moves the ruler up or down. Regression asks the ruler to land on a number. Classification asks a score to become a probability through the sigmoid curve.

<IntuitionCallout>
The important distinction is not “simple model versus complex model.” It is **score versus decision**: a linear score can be optimized smoothly, then a threshold or probability rule turns it into an action.
</IntuitionCallout>

The four moves this week are: derive mean-squared error, solve the normal equation, descend a logistic loss with a stable sigmoid, and understand how L1/L2 regularization changes the geometry of the solution.

## The math, derived

### 1. A line becomes a matrix

For `n` examples with `d` features, let `X ∈ ℝⁿˣᵈ`, `y ∈ ℝⁿ`, and `θ ∈ ℝᵈ`. With an intercept, prepend a column of ones and call the result `\tilde{X}`. The prediction is:

<MathBlock latex="\\hat{y} = \\tilde{X}\\theta" />

The half-scaled mean-squared error keeps its derivative clean:

<MathBlock latex="L(\\theta) = \\frac{1}{2n} \\lVert \\tilde{X}\\theta - y \\rVert_2^2, \\qquad \\nabla_\\theta L = \\frac{1}{n}\\tilde{X}^{\\top}(\\tilde{X}\\theta-y)" />

### 2. Closed form and gradient descent

At a stationary point, the gradient is zero. Rearranging gives the normal equation:

<MathBlock latex="\\tilde{X}^{\\top}\\tilde{X}\\theta = \\tilde{X}^{\\top}y, \\qquad \\theta = (\\tilde{X}^{\\top}\\tilde{X})^{-1}\\tilde{X}^{\\top}y" />

Never form the inverse in production: solve the linear system. Gradient descent takes the same derivative and makes a smaller move:

<MathBlock latex="\\theta_{t+1} = \\theta_t - \\eta \\nabla_\\theta L(\\theta_t)" />

The closed form is a useful oracle for checking the iterative implementation. It becomes less attractive when the feature matrix is too wide or ill-conditioned.

### 3. Logistic loss is a probability model

A logistic model turns a score `z = xᵀθ` into the probability of class one:

<MathBlock latex="\\sigma(z) = \\frac{1}{1+e^{-z}}, \\qquad p(y=1\\mid x)=\\sigma(x^{\\top}\\theta)" />

For a binary target `y ∈ {0,1}`, negative log-likelihood is:

<MathBlock latex="L(\\theta) = -\\frac{1}{n}\\sum_{i=1}^{n} [y_i\\log p_i + (1-y_i)\\log(1-p_i)]" />

The stable equivalent is `log(1 + exp(z)) − yz`, evaluated with a log-sum-exp routine. Its gradient is:

<MathBlock latex="\\nabla_\\theta L = \\frac{1}{n}X^{\\top}(\\sigma(X\\theta)-y)" />

### 4. Regularization changes the question

L2 asks for small weights; L1 asks for sparse weights. With a penalty coefficient `λ`:

<MathBlock latex="L_{L2}=L+\\frac{\\lambda}{2}\\lVert\\theta\\rVert_2^2, \\qquad L_{L1}=L+\\lambda\\lVert\\theta\\rVert_1" />

L2 shrinks continuously. L1 has a kink at zero, so elastic-net implementations usually use a proximal step rather than pretending the derivative exists there.

<Gotcha>Do not regularize the intercept by accident. A constant feature is not evidence that every prediction should be pulled toward zero; regularization belongs on learned feature effects unless you have a specific reason otherwise.</Gotcha>

## The code, from scratch

```python
import numpy as np


def stable_sigmoid(z):
    out = np.empty_like(z, dtype=float)
    positive = z >= 0
    out[positive] = 1 / (1 + np.exp(-z[positive]))
    exp_z = np.exp(z[~positive])
    out[~positive] = exp_z / (1 + exp_z)
    return out


def linear_step(X, y, theta, learning_rate):
    residual = X @ theta - y
    gradient = X.T @ residual / len(y)
    return theta - learning_rate * gradient


def logistic_loss(X, y, theta):
    logits = X @ theta
    return np.mean(np.logaddexp(0, logits) - y * logits)
```

<KeyTakeaways>
- The normal equation and gradient descent optimize the same squared-error objective by different routes.
- Logistic regression is a linear score passed through a sigmoid, not a regression of labels that must be integers.
- `logaddexp` keeps binary cross-entropy finite for extreme logits.
- L2 shrinks weights; L1 encourages exact zeros; neither should quietly regularize the intercept.
- A strong baseline is an experiment control and a debugging instrument, not a disposable first draft.
</KeyTakeaways>
