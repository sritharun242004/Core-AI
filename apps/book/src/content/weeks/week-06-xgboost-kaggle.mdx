<Hook>Why can a model with almost no feature scaling beat a carefully tuned linear model on a spreadsheet? Because trees discover thresholds and interactions—then boosting turns a sequence of small corrections into one strong predictor. This week turns that idea into an offline, schema-checked Titanic-style submission pipeline.</Hook>

<Intuition>
A decision tree asks a sequence of yes/no questions: “Is fare below this threshold?” “Is class 1?” “Is the passenger travelling alone?” Each leaf stores a prediction. The first tree is deliberately weak. Boosting adds another tree aimed at the previous model's mistakes, then another, and another. The final prediction is a weighted sum of small corrections.

<IntuitionCallout>
A useful mental split: **bagging** trains many independent, high-variance trees and averages them; **boosting** trains trees sequentially, with every stage responding to the current residual or loss gradient. Random forests reduce variance. XGBoost is a regularized, second-order boosting system.
</IntuitionCallout>

The four moves to own by the end of the week are: read Gini impurity and entropy as measures of mixed labels; distinguish bagging from boosting; explain XGBoost's first- and second-order loss approximation; and keep every learned preprocessing statistic inside the cross-validation fold.

## The math, derived

### 1. Node impurity: Gini and entropy

Suppose a node has class proportions $p_1, \ldots, p_K$. If we randomly label a row according to the node's empirical distribution, the probability of being wrong is:

<MathBlock latex="Gini(S) = 1 - \sum_{k=1}^{K} p_k^2" />

For four rows with three zeros and one one, $Gini = 1 - (3/4)^2 - (1/4)^2 = 0.375$. A pure node has zero impurity. A binary node with half of each class has the maximum, $0.5$.

Entropy measures the same disorder in bits:

<MathBlock latex="H(S) = -\sum_{k=1}^{K} p_k \log_2 p_k" />

A candidate split divides $S$ into left and right children. The weighted impurity after the split is:

<MathBlock latex="I_{split} = \frac{|S_L|}{|S|}I(S_L) + \frac{|S_R|}{|S|}I(S_R)" />

Choose a split that reduces impurity. This is a local greedy choice, not a guarantee of a globally optimal tree.

<Gotcha>
A deeper tree can always keep splitting until it memorizes the training rows. “The split improved training impurity” is not evidence that it will improve held-out ROC-AUC. Depth, minimum leaf size, shrinkage, subsampling, and early stopping are regularization knobs.
</Gotcha>

### 2. Bagging: variance reduction by resampling

If $T_b(x)$ is the prediction from tree $b$, a random forest averages $B$ trees trained on bootstrap samples:

<MathBlock latex="\hat{f}_{bag}(x) = \frac{1}{B}\sum_{b=1}^{B} T_b(x)" />

For approximately independent errors with variance $\sigma^2$, the average has variance near $\sigma^2/B$. Trees are not independent in reality, so random feature subsets are used to decorrelate them. Bagging fits trees in parallel; it does not use one tree's error to train the next.

### 3. Boosting: additive corrections

Boosting builds an additive model:

<MathBlock latex="F_M(x) = F_0(x) + \eta\sum_{m=1}^{M} f_m(x)" />

Here $\eta$ is the learning rate and each small tree $f_m$ is chosen after seeing the current model. For squared error, a stage can fit the residual $r_i = y_i - F_{m-1}(x_i)$. For classification, we instead use derivatives of a differentiable loss.

### 4. XGBoost's second-order step

For one row, let $\hat{y}_i^{(t-1)}$ be the current prediction and $f_t(x_i)$ the new tree's contribution. A second-order Taylor expansion of the loss gives:

<MathBlock latex="L^{(t)} \approx \sum_i \left[g_i f_t(x_i) + \frac{1}{2}h_i f_t(x_i)^2\right] + \Omega(f_t)" />

where $g_i = \partial_{\hat{y}} l(y_i, \hat{y})$ and $h_i = \partial^2_{\hat{y}} l(y_i, \hat{y})$. For a leaf containing row set $I_j$, with leaf weight $w_j$, the regularized objective is:

<MathBlock latex="\tilde{L} = \sum_j \left[G_j w_j + \frac{1}{2}(H_j + \lambda)w_j^2\right] + \gamma T" />

with $G_j = \sum_{i\in I_j}g_i$, $H_j = \sum_{i\in I_j}h_i$, $T$ leaves, L2 penalty $\lambda$, and per-leaf complexity penalty $\gamma$. Holding a tree structure fixed, differentiate with respect to $w_j$:

<MathBlock latex="w_j^* = -\frac{G_j}{H_j + \lambda}" />

Substituting that optimum gives the leaf's gain contribution:

<MathBlock latex="Gain_j = \frac{1}{2}\frac{G_j^2}{H_j + \lambda}" />

A split is worthwhile only when its children improve the regularized score enough to pay the complexity cost. That is the Newton-step intuition: use slope and curvature, not only a residual.

### 5. SVMs: another boundary, another bias

A linear SVM chooses a large-margin separator. For labels $y_i\in\{-1,+1\}$, the hinge loss is:

<MathBlock latex="L_{hinge}(w,b) = \sum_i \max(0, 1 - y_i(w^T x_i + b)) + \lambda\lVert w\rVert_2^2" />

Only points inside the margin contribute hinge loss. The kernel trick replaces explicit feature expansion with a similarity function such as the RBF kernel:

<MathBlock latex="K(x,z) = \exp(-\gamma\lVert x-z\rVert_2^2)" />

SVMs can be excellent on smaller, carefully scaled datasets. Boosted trees are often a more forgiving first choice for mixed tabular columns, but no method wins by slogan: use an identical split protocol and measure.

## The code, from scratch

The impurity calculation is small enough to write by hand:

```python
import numpy as np

def gini(y):
    _, counts = np.unique(y, return_counts=True)
    probabilities = counts / counts.sum()
    return 1.0 - np.square(probabilities).sum()

def weighted_split_impurity(left, right, impurity=gini):
    total = len(left) + len(right)
    return (len(left) * impurity(left) + len(right) * impurity(right)) / total
```

<KeyTakeaways>
- Gini and entropy measure label mixture; a split is useful only relative to a held-out evaluation protocol.
- Bagging reduces variance through parallel resampled trees; boosting adds sequential corrections.
- XGBoost uses gradient and curvature information, with regularization on leaf weights and tree complexity.
- A preprocessing statistic is learned state. Fit imputers and encoders inside each CV training fold.
- A score improvement on a deterministic fixture is a reproducible teaching result—not a guarantee on real Titanic data or evidence about an undocumented company's internal stack.
</KeyTakeaways>
