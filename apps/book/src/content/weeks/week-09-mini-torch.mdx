<Hook>What if every weight update came with a receipt showing exactly how each input contributed to the loss?</Hook>

<Intuition>
A neural network is a composition of small functions. A linear layer mixes the input features; a non-linearity bends that mixture; another linear layer turns the hidden representation into class scores. Training does not require a mysterious “AI signal.” It requires answering one local question repeatedly: if the final loss moved a little, which direction should each intermediate value move?

<IntuitionCallout>Backpropagation is bookkeeping in reverse. The forward pass saves the graph of dependencies; the backward pass sends a sensitivity from the loss to each parent, multiplying local slopes along the way and adding contributions when a value is reused.</IntuitionCallout>

Think of a package moving through a sorting centre. The forward pass records every conveyor junction. At the end, a damaged package produces a loss. Backprop walks the route backwards, leaving each junction a note: “one extra unit here would have changed the damage score by this much.” A tensor engine is useful because the notes are arrays, not one scalar per neuron.

The four moves are: compose affine maps and ReLUs, reduce a batch of class losses, apply the chain rule in reverse topological order, and update parameters only after all examples have contributed their gradients.

## The math, derived

### 1. A neuron is an affine map plus a gate

Let one batch be $X \in \mathbb{R}^{B\times d}$, a weight matrix be $W \in \mathbb{R}^{d\times h}$, and a bias be $b \in \mathbb{R}^{h}$. The hidden pre-activation and activation are:

<MathBlock latex="Z = XW + b, \qquad H = \operatorname{ReLU}(Z) = \max(0,Z)" />

The bias is broadcast across the $B$ rows. ReLU is deliberately simple: positive coordinates pass through with slope $1$; negative coordinates have slope $0$. A two-layer classifier adds a second affine map, $S = HW_2+b_2$, whose rows are logits rather than probabilities.

For a concrete row $x=(2,-1)$, $w=(0.5,0.25)$, and $b=0.1$, the pre-activation is $2(0.5)-1(0.25)+0.1=0.85$, so ReLU passes $0.85$. If the pre-activation were $-0.2$, the output would be zero and its local derivative would be zero.

### 2. Cross-entropy turns logits into a learning signal

For class logits $s_1,\ldots,s_C$, softmax defines a normalized probability without requiring the model to produce probabilities directly:

<MathBlock latex="p_c = \frac{e^{s_c}}{\sum_{k=1}^{C}e^{s_k}}, \qquad \ell(s,y)=-\log p_y" />

The exponential can overflow for large logits, so the implementation subtracts $m=\max_k s_k$ before exponentiating. Since the same constant cancels between numerator and denominator, this preserves the probability while making the computation safer:

<MathBlock latex="\log p_c = (s_c-m)-\log\!\left(\sum_{k=1}^{C}e^{s_k-m}\right)" />

For a batch, `reduction="sum"` adds each row's loss. `reduction="mean"` divides that sum by $B$; `reduction="none"` keeps the vector so an investigator can inspect hard examples. The mini-torch tests assert all three relationships rather than treating reduction as a cosmetic option.

### 3. The chain rule is a vector-Jacobian product

Suppose $u=f(v)$ and the loss is $L(u)$. Backprop does not need to materialize the full Jacobian. It receives an upstream sensitivity $\bar u=\partial L/\partial u$ and computes:

<MathBlock latex="\bar v = \frac{\partial L}{\partial v} = \frac{\partial u}{\partial v}^{\mathsf T}\bar u" />

For $Z=XW+b$, if $\bar Z$ is known, the useful matrix forms are:

<MathBlock latex="\frac{\partial L}{\partial X}=\bar ZW^{\mathsf T}, \qquad \frac{\partial L}{\partial W}=X^{\mathsf T}\bar Z, \qquad \frac{\partial L}{\partial b}=\sum_{i=1}^{B}\bar Z_i" />

The last sum is the derivative of broadcasting. For ReLU, $\bar Z=\bar H\,\mathbf{1}[Z>0]$. At exactly zero, this teaching engine chooses the zero branch; a framework also has to define a subgradient convention.

### 4. Why reverse mode fits neural-network training

A classifier has many parameters but one scalar loss. Forward mode would carry one tangent per input direction. Reverse mode carries one scalar sensitivity from the loss and reuses it to reach every parameter. If the graph is $v_1\to v_2\to\cdots\to L$, the engine builds a topological order and evaluates local `_backward` closures from $L$ back toward the leaves. Shared parents add their incoming sensitivities:

<MathBlock latex="\frac{\partial L}{\partial x}=\sum_{j\in\operatorname{children}(x)}\frac{\partial L}{\partial v_j}\frac{\partial v_j}{\partial x}" />

This is the core idea behind larger autograd systems, even though production frameworks add compiled kernels, devices, mixed precision, checkpointing, and many more operators.

<Gotcha>Correct values are not enough. A broadcast bias can have a shape-correct forward pass and a wrong backward pass, and a summed loss can make a larger batch look like it has a different learning rate. Inspect shapes and reduction semantics before tuning the optimizer.</Gotcha>

## The code, from scratch

```python
import numpy as np
from mini_torch import MLP, Tensor, cross_entropy, train_mlp

# The engine records parents for @, +, ReLU, exp, log, sum, and mean.
features = Tensor(np.array([[0.2, -0.4], [1.1, 0.7]]), requires_grad=True)
weights = Tensor(np.array([[0.3, -0.8], [0.5, 0.6]]), requires_grad=True)
logits = (features @ weights).relu()
loss = cross_entropy(logits, np.array([0, 1]), reduction='mean')
loss.backward()
print(loss.item(), weights.grad)

# The same graph powers a classifier training loop.
model = MLP(28 * 28, hidden=(32,), out_features=10, seed=7)
history = train_mlp(model, x_train, y_train, epochs=20, learning_rate=0.1,
                     batch_size=50, seed=7)
```

<KeyTakeaways>
- A neural network is a composition of affine maps and nonlinearities; backprop is the chain rule applied in reverse topological order.
- Tensor shapes and broadcasting rules are part of the derivative, not merely forward-pass convenience.
- Stable cross-entropy subtracts a constant max before exponentiation, and reduction controls gradient scale.
- Reverse mode is efficient for one scalar loss and many parameters because one upstream sensitivity reaches every leaf.
- A tiny engine and synthetic fixture can validate implementation plumbing offline; they do not reproduce real MNIST or disclose company internals.
</KeyTakeaways>
