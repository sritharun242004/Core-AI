## Plan your actual calendar

The week numbers are roadmap labels, not a guaranteed completion date. W15 has **15a and 15b**, and **W16 is intentionally absent**. All three specialization tracks are published; choose **two** and complete α then β in each. That is four specialization study weeks, not two. The capstone is approximately 40 hours. At 20 hours per calendar week, reserve about **28 weeks or more**, including extra time for gaps and review.

- **L — LLM product / agents:** [α: bounded agents](/weeks/week-22l-agents-lab) → [β: protocols and economics](/weeks/week-23l-mcp-a2a-adk-lab).
- **P — Applied ML:** [α: retrieval and recsys](/weeks/week-22p-two-tower-recsys) → [β: ranking and forecasting](/weeks/week-23p-learning-to-rank-timeseries).
- **R — Research:** [α: Transformer reproduction](/weeks/week-22r-transformer-repro) → [β: scaling and DPO](/weeks/week-23r-scaling-dpo-repro).

Then build the [capstone](/weeks/week-24-capstone) and run the [interview protocol](/weeks/week-25-interview-prep). Each reference lab has an offline path; optional cloud experiments are separately budgeted and are not prerequisites for running correctness tests. Reading the code does not replace doing the assignments.

## The daily loop

- **Morning (1-2 hrs):** read one section of the current week from **Intuition → Math**.
- **Afternoon (2-3 hrs):** work through **Code from scratch**, then start the **Reference Project**.
- **Evening (30-60 min):** run the **Weekly quiz** or a **MicroRecall** card. Sleep beats cramming.

## The weekly loop (20-22 hrs)

- **Mon / Tue** — sections 1-4 (Hook, Intuition, Math, Code).
- **Wed** — Company Lens + Reference Project start.
- **Thu / Fri** — Reference Project + Assignments (warmup → build → challenge).
- **Sat** — Interview Drill + Weekly Quiz.
- **Sun** — light reading + planning next week.

## The monthly loop

At the end of each Part (1–6), revisit its lesson recall questions, repeat weak interview drills and reproduce one project without notes. There is no separate automated monthly exam; use a written rubric and the interview dashboard to guide review.

## The whole-book loop

- **Weeks 1-4:** Math + programming foundations. **No shortcuts.**
- **Weeks 5-8:** Classical ML. Kaggle-style muscle.
- **Weeks 9-12:** Deep learning + RL primer.
- **Weeks 13-17:** Transformers + LLMs + post-training. This is where the interview questions really are.
- **Weeks 18-21:** Systems, evals, safety.
- **Weeks 22-25:** Pick 2 tracks + capstone + interview prep.

## When to skip

If a section has zero relevance to the roles you're targeting, skip it — but skim the **Hook** and **Interview Angles** anyway. Two minutes of top-of-mind is cheap.
